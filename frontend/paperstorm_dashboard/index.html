How to Operate

操作说明

本地 fake 调试优先，真实 API 再切 paperstorm
提交任务

创建一个 queued 任务，只写入任务状态，不真正调用论文检索或 LLM。

运行选中任务

执行当前 Task ID。fake 模式快速生成示例结果；paperstorm 模式调用真实检索和模型。

轮询选中任务

主动读取任务最新状态、文章、分数、trace 和过程文件，用来确认是否执行完成。

刷新任务列表

拉取服务端所有任务。选择某一条后，Task ID 会回填到顶部输入框。

加载真实任务

根据 Task ID 读取完整 dashboard bundle，适合恢复历史运行结果。

Benchmark

RAG Eval 运行 100 条可审计种子问题，分别显示 Recall、MRR、nDCG、引用、拒答和失败阶段；稳定性压测用于说明 Runtime 可靠性。
